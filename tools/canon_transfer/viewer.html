What is being compared

The baseline is the current committed film-pack-v3 colour recipe, fitted with its post matrix and black/white endpoint weighting. The candidate uses the three Canon-authored display-input recipes, including Portra’s shadow correction, fitted to the same Ricoh format. Both use Medium grain; the new grain is normalized to the same mid-grey luma strength.

All photographs are verified Ricoh Standard JPEGs. Halation, extra softness and extra denoising are off in every variant, so the comparisons isolate colour and grain. The camera-fit preview uses quantized coefficients with identity Standard normalization and a sampled 33³ grid; it is a software reference, not a physical-camera measurement. Full-LUT mode shows the unfitted offline target and does not imply the camera can reproduce it exactly.

Crop views are extracted at the same source coordinates. Grain uses the full source’s coordinates, scale and seed. The forest source is already reduced to 2400 pixels; its crop is not a full-resolution camera crop. Full-frame images are review JPEGs; crop files are lossless PNGs.
