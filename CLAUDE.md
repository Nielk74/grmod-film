# Project focus

## Film emulations

We need to focus on a set of important film emulations: Portra 400, CineStill, Gold, ... (open to more).
Put the effort into getting these few right before spreading it across the whole pack.

## Colour

We can probably find other axes of global improvement for emulating, or improving, overall colours.
Look for them: the camera renders a film with one matrix, three curves and a post matrix, so
global changes are what it can hold (a colour-selective change needs the hue stage).
